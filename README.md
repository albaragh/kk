# ممالك الشفق — Kingdoms of Twilight

لعبة عالم مفتوح ثلاثية الأبعاد في المتصفح. العربية هي لغة الواجهة، والإنجليزية من الإعدادات.

## التشغيل

```bash
npm install
npm run dev
```

ثم افتح الصفحة الرئيسية. جودة متوسطة بلا ظلال، وعالية لمن يريد ظلالًا.

## البناء

```bash
npm run build
npm run preview
```

## التحكم

- WASD أو الأسهم: حركة نسبية للكاميرا. A يسار الشاشة، D يمينها.
- الفأرة: تدوير الكاميرا. نقرة خفيفة: هجوم.
- مسافة: قفز، واستمرار الضغط انزلاق بعد الحصول على الجناح.
- C مراوغة، J خفيف، K ثقيل، F صدّ.
- 1 رمل، 2 برق، 3 ريح، E تفاعل، G خطاف.
- M خريطة، I حقيبة، U مهارات، L مهمات، Esc إيقاف.

على الجوال: عصا يسار، وسحب يمين للكاميرا، وأزرار الأفعال.

## الحفظ

داخل المتصفح فقط، من قائمة الإيقاف أو تلقائيًا أثناء اللعب.

التفاصيل في `docs/`.
