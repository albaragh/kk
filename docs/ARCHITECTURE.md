# البنية

العميل فقط. لا حسابات ولا قاعدة بيانات. الحالة في `GameSim` وتُعرض عبر React Three Fiber، والواجهة DOM فوق الكانفس.

- `src/game/world.ts` ارتفاع الممالك والطرق والمباني والدعائم.
- `src/game/content.ts` أغراض، مهمات، حوارات، أعداء، تفاعل.
- `src/game/logic.ts` دوال خالصة للضرر وتقدّم المهمات.
- `src/game/sim.ts` حلقة اللعب بخطوة ثابتة 1/60.
- `src/game/scene.tsx` التضاريس المدمجة، السماء، الشخصيات.
- `src/game/hud.tsx` القوائم العربية.
- الحفظ والصوت في `save.ts` و`audio.ts`.

التضاريس دالة حتمية، لذلك الارتفاع في الفيزياء هو نفسه ارتفاع المضلع. المباني مدمجة حسب الخامة. الدعائم `InstancedMesh`. الضباب والإخفاء حسب المسافة للأعداء.

لماذا ليست Rapier: عالم مفتوح بارتفاع تحليلي أوضح وأصغر على الجوال من حزمة WASM، والتصادم صناديق وأسطوانات مع الارتفاع. الكاميرا والشخصية لا تشاركان متجهًا مؤقتًا واحدًا.
