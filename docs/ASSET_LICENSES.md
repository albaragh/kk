# تراخيص الأصول

لا نماذج خارجية ولا صور مولَّدة مستخدمة داخل المشهد الثلاثي الأبعاد.

- التضاريس والمباني والنخيل والشخصيات والواجهة: هندسة وإجراءات أصلية في الكود (Three.js).
- الخطوط: Cairo وAmiri من Google Fonts عند توفر الشبكة، مع بدائل النظام العربية.
- الصوت: مذبذبات Web Audio مولَّدة وقت التشغيل، بلا ملفات.
- بطاقة المشاركة والأيقونة: أصول الهوية في `public/` صنعت لمشروع اللعبة.

لا مكتبات مدفوعة ولا مفاتيح سرية.
