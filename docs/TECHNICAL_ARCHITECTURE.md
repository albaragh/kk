# البنية التقنية

تطبيق TanStack Start (React 19) مع Three.js و React Three Fiber. لا Drei ولا Rapier. فيزياء السيارة طبقة آركيد خاصة في `src/game/physics.ts`.

التقدم محلي فقط (`localStorage`، المفتاح `midnight-rush-v1`). لا حسابات ولا قاعدة بيانات.

## الملفات

| مسار | دور |
|---|---|
| `src/game/physics.ts` | تسارع، سحب، تماسك، فرامل يد، سطح الطريق، غيار، نيترو |
| `src/game/sim.ts` | العالم اللحظي: لاعب، منافسون، مرور، عدّ السباق |
| `src/game/world.ts` | طرق، مبانٍ، أسطح، بوابات، تصادم |
| `src/game/cars.ts` | 30 سيارة وتكلفة الترقيات |
| `src/game/store.ts` | اقتصاد وحفظ وشاشات |
| `src/components/game/*` | المشهد، السيارات، الخريطة المصغرة، القوائم |

المحاكاة لا تستورد المتجر. الجسر `src/game/bridge.ts` يمرر الإعداد والنتيجة.

## الزمن والتحكم

خطوة ثابتة 1/60. الإطار البطيء يلحق حتى 0.2 ثانية حتى لا يتجمد العد التنازلي إذا تعثّر الرسم. التوجيه: A أو السهم الأيسر يزيد الانعراج (يسار الكاميرا الخلفية)، وD ينقصه. الرجوع للخلف يعكس التوجيه. عصا اليد: اليمين توجيه سالب.

نسخة المحاكاة واحدة على `globalThis` حتى لا ينقسم الحالة عند تحديث الصفحة أثناء التطوير.

## الرسم

طرق بـ BufferGeometry، مبانٍ وأعمدة بـ InstancedMesh مع إخفاء البعيد. سيارات بارامترية بعجلات تدور وأضواء. كاميرا خلفية / غطاء / مصد. جودة منخفضة على شاشة اللمس.

## الاختبار الآلي

`npx tsx --test src/game/logic.test.ts`

يغطي إشارة التوجيه، التسارع، اتجاه البوابات، نقاط الانطلاق على الطريق، أثر الترقية، وإنهاء حلقة الأفق مع زيادة الرصيد.
